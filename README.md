# 📊 Visualize - 図解アプリケーション

ユーザーが入力したテキストを自動的に図解するビジュアライゼーションアプリケーションです。

## 🌐 デモ

**本番環境**: https://yama2024.github.io/visualize/

今すぐ試してみてください！

## ✨ 特徴

- **自動図解**: テキストを入力するだけで、適切な図を自動生成
- **複数の図タイプ**: フローチャート、シーケンス図、マインドマップ、ガントチャート、円グラフに対応
- **日本語対応**: 日本語で自然に入力できます
- **リアルタイム生成**: ボタンクリックで即座に図を表示
- **レスポンシブデザイン**: PC、タブレット、スマートフォンで利用可能

## 🚀 使い方

### 1. アプリケーションを開く

ブラウザで `index.html` を開いてください。

```bash
# ローカルサーバーで起動する場合
python -m http.server 8000
# または
npx serve
```

ブラウザで `http://localhost:8000` にアクセスします。

### 2. テキストを入力

左側の入力エリアに図解したい内容を自由に入力してください。

### 3. 図の種類を選択（オプション）

- **自動判定**: 入力内容から最適な図を自動選択（デフォルト）
- **手動選択**: 上部のボタンから図の種類を明示的に選択

### 4. 図解を実行

- 「図解する」ボタンをクリック
- または `Enter` キーを押す（改行は `Shift + Enter`）

## 📝 入力例

### フローチャート

```
開始 → データ入力 → 処理の実行 → 結果の確認 → 終了
```

### シーケンス図

```
ユーザー、システム、データベースの関係。
ユーザーがログイン要求。
システムがDBに認証問い合わせ。
DBが認証結果を返す。
システムがユーザーに結果を通知。
```

### マインドマップ

```
Webアプリケーション開発:
フロントエンド(React, Vue, Angular),
バックエンド(Node.js, Python, Java),
データベース(MySQL, MongoDB, PostgreSQL)
```

### ガントチャート

```
プロジェクト計画。
要件定義: 2024-01-01から2024-01-15。
設計: 2024-01-16から2024-02-15。
開発: 2024-02-16から2024-04-30。
```

### 円グラフ

```
売上構成:
製品A 40%,
製品B 30%,
製品C 20%,
その他 10%
```

## 🎯 サポートされる図のタイプ

| 図の種類 | 説明 | キーワード例 |
|---------|------|------------|
| フローチャート | 処理の流れを表現 | 「→」「から」「次に」 |
| シーケンス図 | システム間のやりとり | 「やりとり」「問い合わせ」「応答」 |
| マインドマップ | 階層構造や関係性 | 「:」「()」「分類」 |
| ガントチャート | 時系列のスケジュール | 「期間」「から〜まで」「日付」 |
| 円グラフ | データの割合 | 「%」「割合」「構成」 |

## 🛠️ 技術スタック

- **HTML5/CSS3**: UI構築
- **JavaScript**: ロジック実装
- **Mermaid.js**: 図の描画エンジン

## 📦 依存関係

- Mermaid.js v10（CDN経由で読み込み）

## 🌐 ブラウザ対応

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 💡 使い方のコツ

1. **簡潔に書く**: 各要素を短く、明確に記述
2. **区切り文字を使う**: 「→」「、」「。」などで要素を区切る
3. **キーワードを含める**: 図の種類に応じたキーワードを含めると認識精度が向上
4. **サンプルを活用**: 画面内のサンプルをクリックして試してみる

## 🔧 カスタマイズ

### テーマの変更

`index.html` の `mermaid.initialize()` セクションで設定を変更できます:

```javascript
mermaid.initialize({
    theme: 'dark', // 'default', 'dark', 'forest', 'neutral'
    // その他の設定...
});
```

### 色の変更

CSSの `:root` セクションでカラーパレットをカスタマイズできます。
